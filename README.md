# TFTP-server-and-client
TFTP Server and Client is a C-based client-server application that transfers files using UDP socket programming. It supports file upload and download through RRQ, WRQ, DATA, ACK, and ERROR packets, demonstrating networking, socket programming, file handling, and client-server communication.

## Features

- Client-server communication using UDP
- File upload from client to server
- File download from server to client
- RRQ (Read Request)
- WRQ (Write Request)
- DATA packet handling
- ACK (Acknowledgement) handling
- ERROR packet handling
- File read/write operations
- Packet-based file transfer

## Technologies Used

- C Programming
- Linux
- UDP
- Socket Programming
- File Handling
- Network Programming
